# Thumbnail prompts — "Could L Catch Spider-Man?"

Generated for use with an external AI image tool (Grok, ChatGPT/DALL-E, Midjourney,
Magnific, etc.) — this repo doesn't have image-generation access, so these are
meant to be pasted into whichever tool is used to produce the final art.

All concepts use the reference channel's format: split-face mugshot, height-ruler
lineup backdrop, warm/cool duotone per side. YouTube auto-adds the duration badge,
so none of these bake one in.

## Concept 1 — Main mugshot (recommended default)
Text overlay: none

> Photorealistic/anime-hybrid YouTube thumbnail, 1280x720, symmetrical split-face
> composition divided by a hard vertical seam down the center. Left half:
> Spider-Man's masked face, close-up, against a red spider-web-textured mugshot
> backdrop with horizontal height-ruler lines (police lineup style, ft/in
> markings). Right half: L from Death Note, pale anime face, close-up, against a
> cool grey-blue mugshot backdrop with matching height-ruler lines. Small black
> Death Note book icon tucked in the lower-left corner. No text overlay. High
> contrast, dramatic lighting, poster-quality digital art.

## Concept 2 — Eyes-only close-up
Text overlay: "CAUGHT?" bold white condensed sans-serif, upper third

> the eyes and brow, red web texture bleeding into cool blue-grey on the right,

## Concept 3 — "IDENTIFIED" stamp
Text overlay: diagonal red "IDENTIFIED" stamp across the seam
