# Harper Lane Films — Episode 001: Location Reference

Anchor prompts for every recurring location in "Before I Let You Go." Generate each one once,
then use it as the image-to-image background reference for every scene set there — same method
as the character bible's anchor images, applied to environments instead of faces.

---

## Production notes
- Generate in scene-frequency order: Josephine's front/dining first (6 scenes), then the Carter
  kitchen (3 scenes), then back office, living room, and the bar last (single use each).
- Once a location's anchor image exists, combine it with the relevant character's anchor/sheet
  image when generating a populated scene shot, if the tool supports multi-image reference. If
  not, generate the empty environment first and composite the character in during the CapCut
  edit, same fallback logic as character consistency.
- Lighting language matches the locked warm/naturalistic visual identity for this channel —
  don't drift toward Logic Nexus's cooler noir grade.
