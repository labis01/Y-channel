Shot numbers match `could-l-catch-spider-man-visual-prompts.md`. Only the AI shots are here; stock clips and your own cold-open images are listed in that file.

## Before you start
1. In Grok Imagine, set the aspect ratio to **16:9** before you generate.
2. Paste **one prompt at a time**. Grok doesn't remember earlier images, so every prompt repeats the character description in full. Don't shorten it.
3. **Same faces every time:** attach your cold-open image of Peter or L, then add this at the start of the prompt: `Same person as in the attached image.`
4. **No text in images.** Grok garbles words. Add timestamps, notes and headlines in CapCut.
5. **Video:** for the shots marked 🎬, open the image and press "Make video", then paste the motion line. Each one gives you a 6-second clip.
6. If Grok refuses a "Spider-Man" shot, keep the prompt as it is. It already describes the suit without the name.
