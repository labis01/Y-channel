# Harper Lane Films — Episode 001: Scene-by-Scene Image Prompts

Ready-to-paste Grok prompts for all 14 scenes. Each entry lists which reference images to attach
(location anchor + character anchor/sheet image) and the specific outfit for that character in
that scene, pulled from their wardrobe list in the character bible. Attach the reference image(s)
noted, then paste the prompt text.

If Grok struggles to hold two character faces accurately at once, prioritize whichever character
has more screen time/close-up focus in that scene and describe the second character in text only.

**Dani's outfit:** Working at Josephine's (dark apron over a cream henley)

## Production notes
- Generate roughly in script order — each scene's location is likely already needed from an
  earlier scene, so this keeps you from re-fetching reference images out of sequence.
- Scenes 5+6 and 8 (back office) share exact outfits/lighting with their neighboring scenes —
  batch those together if working scene-by-scene gets repetitive.
- If a location anchor hasn't been generated yet when you reach a scene, generate it first (see
  `harper-lane-001-locations.md`), then come back to the scene prompt.
