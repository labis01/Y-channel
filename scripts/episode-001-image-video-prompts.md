# Episode 001 — "What If YOU Faked Your Own Death?" — Image/Video Prompt List

Status: Prompt list locked, ready for generation. Script is locked (see
`what-if-you-episode-001-faked-death.md`). Per updated sequencing rule in CLAUDE.md, narration
gets recorded LAST — after the CapCut edit is assembled — so scenes below can shift during
generation without needing a narration re-record.

**Image count scales with narration length, not a flat 2-per-block.** A block covering ~15-25
seconds of narration gets 2 images; a block covering 35-65+ seconds gets 3-5, so no single image
ever has to carry more than roughly 13-15 seconds of screen time. This is a direct fix for the
repeated-image problem on the first video — running short on generated images and reusing the
same frame across a long narration stretch. Counts below were calculated from the actual locked
script's word count per section (at 184 wpm) divided across that section's blocks.

De-risking: all prompts below are generic/descriptive only — no trademarked names, no direct
character references. This episode has no franchise-character cameo in the visuals except L, who
uses the channel's standard generic descriptor. 16:9, photorealistic, cool desaturated noir grade
throughout (matches the established channel look).

## Character anchors (reuse exactly, for visual consistency across all blocks)

- **"You" (the protagonist/suspect):** a man in his late 30s, short dark hair, tired eyes, plain
  gray or dark jacket, unremarkable/ordinary appearance — never show his face in a clear
  identifiable close-up if you want to preserve the "self-insert" feel; hands/back/silhouette
  framing is fine and often stronger anyway.
- **L (the detective):** the pale detective — slight build, messy dark hair, pale skin, dark
  circles under the eyes, hunched/crouched posture, plain long-sleeved top. (Standard channel
  descriptor — reuse from prior case files.)
- **The accomplice:** a nervous-looking person in their 30s, plain clothing — no need for strict
  visual continuity beyond their own scenes since it's a minor character.

## Legend
- **STILL** = generate as a static image, animate with CapCut Ken Burns/keyframe zoom — cut
  between the listed variants across the beat instead of parking on one frame
- **VIDEO** = one of the 3 real AI motion clips (image-to-video via Google Flow) — continuous
  motion covers its own screen time, no extra stills needed
- **B-ROLL** = pull from Pexels instead of generating
- **GRAPHIC** = build directly in Canva (not AI-generated)

**Total generation budget for this episode: ~47 stills + 3 b-roll clips + 3 motion clips + 3
graphics ≈ 56 pieces.** That's more than Episode 001's first prompt-list draft — split the load
across tools (Grok, Gemini, Bing, Canva Magic Media) from the start rather than relying on one,
especially with Grok's 2026 shared weekly pool covering both chat and media generation.
